## Contributing

Once the repository is public, contributions should explain the proposed change and its purpose. Report technical issues with a concise description and steps to reproduce. Do not use public issues for private corrections, source identities or sensitive case material; use the appropriate email contact.

> **Never commit private submissions, personal data, credentials or confidential evidence.** A public source repository is visible to everyone and is not a place to store correspondence or source material.
