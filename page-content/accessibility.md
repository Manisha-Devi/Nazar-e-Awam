# Accessibility

**Route:** `/accessibility`

**Eyebrow:** Access for everyone

We aim to make this publication readable and usable across devices, assistive technologies and different ways of navigating.

## Our accessibility goals

- Keyboard navigation and visible focus states.
- Semantic page structure and a clear heading hierarchy.
- Descriptive link text and labels for search controls.
- Readable colour contrast, line lengths and responsive layouts.
- Meaningful alternative text for informative images.
- Respect for reduced-motion preferences.

We will address barriers as they are identified; this statement is an ongoing goal, not a claim of formal certification.

## Report an access issue

Tell us which page or feature is difficult to use and, if possible, what device or assistive technology is involved. **Email an accessibility issue.**
